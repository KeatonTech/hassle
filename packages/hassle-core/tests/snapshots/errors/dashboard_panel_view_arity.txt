The `panel` view opened at test_dashboard_errors.py:<line> contains 2 cards. HA's panel view renders exactly one card at full width, so any other number cannot be stored faithfully -- HA would show only the first card and quietly lose the rest. Fix: keep exactly one card in the view (group several inside one stack card), or change it to `view(type="sections")`/`view(type="masonry")`, which both take any number of cards.
