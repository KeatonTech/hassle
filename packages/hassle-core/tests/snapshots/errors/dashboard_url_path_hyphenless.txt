`@dashboard(url_path='climate')` at bad.py:6 has no hyphen in its `url_path`. Home Assistant requires a dashboard's `url_path` to contain a hyphen (its own frontend and backend both enforce it on everything you can create through the UI), so no dashboard with this `url_path` can exist to push to. Fix: rename it to a hyphenated slug, e.g. `url_path="climate-dashboard"`. (The one exception is `"lovelace"`, which is HA's own `url_path` for the default dashboard once HA has migrated it to a registry item -- Hassle accepts that one.)
