`view(extra={'title': ...})` at test_dashboard_errors.py:<line> sets `title`, which is already a declared keyword of `view`. `extra=` is the forward-compatibility valve for card options Hassle does not model yet; letting it also spell a modelled option would give that option two spellings, so a decompiled dashboard could never be byte-stable. Fix: pass `title=` as an ordinary keyword argument and remove it from `extra=`.
