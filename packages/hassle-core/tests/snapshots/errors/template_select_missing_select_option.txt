`template_select(name='House Scene', ...)` at test_template_helper_write_target_error.py:<line> is missing the required `select_option=` keyword. HA's `template` config flow requires a write-target action sequence for a writable `template_select` helper -- `state` alone only computes the displayed value, so the form schema rejects a submission without one. Fix: pass `select_option=` with the action (or list of actions) to run when the helper is written from the UI/a service call, e.g. `template_select(name='House Scene', ..., select_option={"action": "input_select.select_option", "target": {"entity_id": "input_select.example"}, "data": {"option": "{{ option }}"}})`.
