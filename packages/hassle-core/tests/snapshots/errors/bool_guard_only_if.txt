A bare `bool` can never be a real Home Assistant condition -- this is almost always the `==`/`!=`-on-a-plain-value mistake (comparing two ordinary Python values instead of building a condition). Fix: build an actual condition, e.g. `entity.state == "on"` / `entity.state.is_not("on")` (M20's entity-first accessor) or `state(entity_id).is_("on")` (the classic builder), and pass THAT to `only_if(...)` -- never a bare `bool`.
