`action` was called inside a `@dashboard` body at test_dashboard_errors.py:<line>, which records cards -- not triggers, conditions or actions. A Home Assistant dashboard has no action list of its own: it describes what to DISPLAY, and anything it runs is an option ON a card (`tap_action`, `hold_action`, a button card's target). Fix: to make a card do something when tapped, set that option on the card itself (e.g. `raw_card({..., "tap_action": {"action": "perform-action", "perform_action": "light.turn_on"}})`); to automate something instead, move this call into an `@automation`/`@script` function body.
