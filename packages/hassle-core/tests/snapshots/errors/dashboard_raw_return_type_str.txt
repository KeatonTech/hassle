The `@raw_dashboard` body for `weird-one` returned a `str`, not a `dict`. A raw dashboard's body must return either the whole `{"meta": ..., "config": ...}` envelope or just the Lovelace config dict; anything else would be stored as the dashboard's config as-is, so a push would overwrite the real dashboard with it. Fix: `return` a dict from this function -- e.g. `return {"views": [...]}` for a config, or `return {"meta": {"url_path": "..."}, "config": {...}}` for the full envelope. Raw bodies take dicts, never YAML strings (§5.5).
