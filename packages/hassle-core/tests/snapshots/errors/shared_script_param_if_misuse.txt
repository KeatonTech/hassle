You used Python's `if/bool()` on the shared-script parameter `tag` at scripts.py:15. Since M19, `tag` inside this body is bound to its runtime `param('tag')` marker (regardless of its declared default), so it has no compile-time value to give `if/bool()` -- it is Jinja text under construction, not a number or a boolean, until it renders inside Home Assistant. Fix: for deliberate compile-time metaprogramming (e.g. unrolling a `for _ in range(...):` loop a fixed number of times), use `param_default('tag')` instead -- it returns `tag`'s DECLARED default, a plain Python value, not the runtime marker.
