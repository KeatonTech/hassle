The blueprint input `orphan` is declared at module scope but no blueprint references it. A module-scope `bp_input(...)` joins a blueprint's input schema by being USED in its triggers, conditions or actions (docs/internals/blueprints-design.md §8.2), so a declaration nothing references is emitted into no blueprint document at all -- it is dead code rather than a bundle-wide default at shared.py:4 Fix: reference `orphan` from a blueprint's triggers or actions, or delete the declaration. If you meant a constant shared across the bundle rather than a blueprint input, a plain Python value is the right tool -- an input only exists to be filled in per instance.
